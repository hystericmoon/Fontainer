# Fontainer Companion — Figma Plugin

Scan any Figma page for missing fonts, open them in Fontainer for 1-click Mac/Windows OS activation, and apply live Fontshare / Collletttivo / Open Foundry / UNCUT / Google Fonts straight onto selected text layers.

## Install in Figma Desktop (3 Steps)
1. Open **Figma Desktop**.
2. Go to **Plugins → Development → Import plugin from manifest…**.
3. Select `plugins/fontainer-figma/manifest.json` from this repository.

## Usage
- **Page & Missing Tab:** Automatically lists all missing fonts on the current Figma page with a 1-click **"Activate in Fontainer"** link.
- **Live Apply Tab:** Search any Fontshare, Indie Foundry, or Google Font and click **Apply** to update your selected text layers immediately.
