Fontainer Privacy Policy

Effective date: November 22, 2026 · Applies to the Fontainer web application (https://fontainer-alpha.vercel.app) and the Fontainer macOS desktop application.

1. Overview & Local-First Design

Fontainer is a font manager for web and macOS designed around a local-first architecture. You can browse live Google Fonts, inspect OpenType features and glyphs, compare typefaces, and preview local font files without creating an account. Signing in with Google is entirely optional and is used only when you choose to sync your font lists and workspace preferences across devices or import font files from your Google Drive.

2. Data We Collect and How We Use It

  • Google Account Information (Optional Sign-In): When you click Sign in with Google, Fontainer uses Firebase Authentication to receive your basic Google profile information (unique user ID, display name, email address, and profile avatar URL). This data is used solely to authenticate your session, identify your private cloud sync workspace, and display your signed-in account inside the app.
  • Font Workspace & Organization Metadata (Optional Cloud Sync): When signed in, Fontainer saves your custom Font Lists, Smart Lists, connected Adobe Fonts Project IDs, font tags, personal usage notes, starred/activated font flags, and UI preferences (theme, preview text, font size) in a private Google Cloud Firestore database scoped strictly to your user ID so your organization stays synchronized across your devices.
  • Local & Imported Font Files: Font files you drag-and-drop or import from your computer (.ttf, .otf, .woff, .woff2) are parsed locally in your browser or desktop app using OpenType.js and stored locally on your device. Fontainer never uploads your local font binaries to Fontainer servers.
  • AI Font Pairing Requests: When you explicitly click Suggest Pairings in the Inspector panel, Fontainer sends only the selected typeface’s non-personal metadata (font family name, classification, weight list, selected layout context such as SaaS/Editorial, and any optional project mood notes you type) to our server-side Gemini API proxy to generate complementary Google Fonts recommendations.
  • Operational Server Logs: Standard HTTP request metadata (IP address for short-lived rate limiting, requested API path, status code) may be processed transiently by our hosting provider (Vercel) to protect service availability and prevent abuse.

3. Google Drive Data & Google API Limited Use Policy

Basic Sign in with Google in the sidebar does not request access to Google Drive. Only if you explicitly open Sources → Cloud Drives and click to connect Google Drive does Fontainer request the read-only scope https://www.googleapis.com/auth/drive.readonly. That permission is used exclusively to:

  • List font files (.ttf, .otf, .woff, .woff2) stored in your Google Drive so you can browse and choose which ones to preview.
  • Download only the specific font files you select directly from Google Drive into your local browser or macOS app session for live font inspection.

Token & Data Protection: Your Google Drive OAuth access token is held strictly in ephemeral in-memory JavaScript state for the active session and is never stored in cookies, browser localStorage, or Fontainer backend databases. Fontainer never modifies, deletes, or shares any file in your Google Drive.

Fontainer’s use and transfer to any other app of information received from Google APIs strictly adheres to the Google API Services User Data Policy, including the Limited Use requirements. We do not sell Google user data, do not use it for advertising, and do not use Google Drive data or personal user data to train generalized AI/ML models.

4. Data Sharing & Third-Party Infrastructure

Fontainer does not sell, rent, or trade your personal information. We rely on the following trusted infrastructure providers strictly to deliver app functionality:

  • Google Firebase (Authentication & Cloud Firestore): Optional user authentication and per-user cloud sync storage protected by strict owner-only Firestore security rules.
  • Vercel: Web hosting and serverless API execution for Fontainer’s catalog and pairing endpoints.
  • Google Fonts & Adobe Fonts (Typekit): Live webfont directory metadata and font stylesheets loaded on demand.
  • Google Gemini API: Server-side typographic pairing generation when explicitly requested by the user.

5. Data Retention, Security & Your Deletion Rights

  • Local Data: You can clear local workspace preferences and imported local fonts at any time from Preferences → Reset Local Workspace or by clearing site storage.
  • Revoking Google Access: You can sign out inside Fontainer at any time and revoke Fontainer’s Google permissions at myaccount.google.com/permissions.
  • Account & Cloud Data Deletion: Your synced Firestore records are retained only while you maintain an active workspace. To request permanent deletion of your synced cloud records and Firebase account data, email us at the contact address below and we will fulfill deletion promptly.
